# Промпт: список ссылок Sketchfab → файлы с подписями для БД

Скопируйте блок ниже в нейросеть (нужна та, что умеет открывать ссылки) и приложите файл со ссылками (например, `Машины(1).txt`).
Результат — папка `labels/`, которую достаточно положить в проект: по ней модели заводятся в БД (`car_assets`, реестр `data/catalog/sketchfab_models.json`).

---

```
Ты — помощник, который готовит метаданные 3D-моделей машин для базы данных сайта подбора автомобилей.

ВХОД
Файл со ссылками на модели Sketchfab (формат https://skfb.ly/XXXXX, по одной в строке). Пустая строка разделяет группы:
в одной группе обычно варианты одной и той же машины от разных авторов. Номер группы = порядковый номер блока (с 1).

ЗАДАЧА
Для КАЖДОЙ ссылки открой страницу модели на Sketchfab и составь один JSON-файл с подписью. Ничего не выдумывай:
если на странице этого нет — ставь null и объясняй в "notes". Если страница недоступна — "status": "unreachable".

ШАГИ
1. Открой короткую ссылку, запомни конечный адрес вида https://sketchfab.com/3d-models/<название>-<uid>.
   uid — последние 32 шестнадцатеричных символа адреса.
2. С самой страницы возьми: название, автора и ссылку на автора, лицензию (название и ссылку на текст),
   можно ли скачать (Downloadable), число полигонов/треугольников (Triangles/Faces), теги, описание, дату публикации.
3. По названию, описанию и тегам определи машину: марка, модель, поколение/кузов (например F01, W223), год выпуска или
   диапазон лет, тип кузова, число дверей. Если что-то можно только предположить — ставь null и "confidence": "low".
4. Оцени пригодность модели (по описанию, тегам и превью; ничего не додумывай):
   - это одна целая машина, а не сцена, не набор деталей и не разбитая/ржавая/сканированная модель;
   - есть ли салон (руль, сиденья), отдельные ли колёса;
   - не мультяшная/low-poly/игрушечная;
   - число полигонов: удобно 20 000 – 1 200 000; больше — "too_heavy", меньше — "too_simple".
5. Проверь лицензию:
   - "ok" — CC0, CC BY, CC BY-SA;
   - "nc" — есть NonCommercial (годится только для демо);
   - "blocked" — есть NoDerivatives (ND) или Sketchfab Standard / «Editorial» / «Store» / любая платная;
   - "unknown" — не нашёл.
   Скачиваемость и лицензия — главное условие. Если не Downloadable — "usable": false.
6. Внутри группы выбери лучшую модель: рекомендовать ту, у которой usable=true, лицензия ok, есть салон, адекватная
   сложность, больше деталей. Только у одной модели группы "recommended": true (если подходящих нет — ни у одной).

ВЫХОД
Папка labels/ со следующими файлами. Каждый файл — валидный JSON в UTF-8, без комментариев и без текста вокруг.

1) labels/<short_code>.json — по одному на ссылку (short_code — часть после https://skfb.ly/):

{
  "short_code": "pMwP8",
  "group": 1,
  "status": "ok",                       // ok | unreachable | not_a_car
  "uid": "a57b6861ac164e10847861c5b9a30ca3",
  "url": "https://sketchfab.com/3d-models/...-a57b6861ac164e10847861c5b9a30ca3",
  "short_url": "https://skfb.ly/pMwP8",
  "title": "название модели точно как на Sketchfab",
  "author": "ник автора",
  "author_url": "https://sketchfab.com/...",
  "license": "CC Attribution",
  "license_url": "https://creativecommons.org/licenses/by/4.0/",
  "license_class": "ok",               // ok | nc | blocked | unknown
  "downloadable": true,
  "faces": 3517961,
  "complexity": "too_heavy",           // ok | too_heavy | too_simple | unknown
  "published": "2024-05-03",           // дата публикации или null
  "car": {
    "brand": "Mazda",                  // как пишут на русском сайте: Lada, Kia, Toyota, Mercedes-Benz, BMW...
    "model": "CX-5",
    "generation": "KF",                // код поколения/кузова или null
    "year_from": 2017,                 // год выпуска из названия; если указан диапазон — год начала
    "year_to": null,
    "body": "suv",                     // sedan | hatch | suv | wagon | minivan | null
    "doors": 5,
    "confidence": "high"               // high | medium | low
  },
  "quality": {
    "single_car": true,
    "has_interior": true,
    "separate_wheels": true,
    "stylized": false,
    "damaged_or_scan": false
  },
  "usable": false,                     // true только если скачивается, лицензия ok или nc, это одна нормальная машина
  "recommended": false,                // лучший вариант в группе
  "credit": "«2017 Mazda CX-5» — Res1n (Sketchfab), CC Attribution",
  "caption_ru": "Mazda CX-5, 2017 · модель Res1n, CC BY 4.0",
  "notes": "кратко, что вызывает сомнение или почему не подходит"
}

2) labels/index.json — массив из всех файлов выше в порядке ссылок (то же содержимое, одним файлом).

3) labels/report.md — короткий отчёт: сколько ссылок обработано; сколько usable; список проблем
   (недоступные страницы, нескачиваемые, запрещённые лицензии, не машины); по каждой группе — какая модель рекомендована и почему.

ПРАВИЛА
- Данные только со страницы модели. Никаких догадок про марку и год «по виду»: нет в тексте — null.
- Название и ник автора копируй символ в символ.
- Не придумывай uid и ссылки; если не получилось открыть страницу — "status": "unreachable" и пустые поля null.
- Не скачивай сами модели и не обходи ограничения Sketchfab. Нужны только метаданные.
- Ответ — только файлы/JSON и отчёт, без пояснений в чате.
```

---

## Что делать с результатом

1. Положить папку `labels/` в проект (например, `data/labels/`).
2. Прислать мне — я заведу `usable`-модели в реестр `data/catalog/sketchfab_models.json`, привяжу к машинам каталога (`brand` + `model` + `year`),
   а GLB-файлы они скачиваются отдельно (`tools/import_models.py`: из папки `data/models_inbox/<uid>.glb` или через `SKETCHFAB_TOKEN`).
3. Модели с `license_class: "blocked"` или `downloadable: false` в БД не попадут.

# 3D-тест на лося

Тест идёт **в той же сцене, что и экскурсия**: та же улица, та же машина, тот же renderer.
Отдельного окна нет, сцена не сбрасывается: камера плавно перелетает из ракурса экскурсии и
по закрытии возвращается обратно. 2D-сцена (`moose2d.js`) осталась только запасным вариантом,
если 3D не загрузилось.

Исход всегда берётся из API `/api/v1/cars/{id}/moose?speed=` (объезд: pass / limit / fail+skid /
fail+rollover; удар: уровень, `impact_speed`, `roof_hit`, травмы по местам). Анимация только
показывает этот исход и не противоречит ему.

## Файлы

| Файл | Что там |
|---|---|
| `app/static/js/moose3d.js` | `StreetLoop`, `Dummy`, `Crumple`, `MooseTest` — весь тест |
| `app/static/js/viewer.js` | только крючки: `this.test`, `localClippingEnabled`, `this.street`, передача `dt` в тест |
| `app/static/js/app.js` | панель теста поверх сцены (скорость, сценарий, камеры), fallback на 2D |
| `app/static/css/app.css` | HUD: подпись, спидометр, крен, «Замедленно ×3» |
| `app/static/media/moose/mannequin.glb` | шарнирный манекен (собирается скриптом ниже) |
| `tools/prepare_mannequin.py` | Blender: делит деревянный манекен на сегменты с шарнирами |

## Что исправлено после первой версии (другой нейросети)

- **Тест открывался отдельным окном и сбрасывал сцену** — код удалён из `viewer.js`, тест
  переписан модулем, который работает внутри сцены экскурсии.
- **Дорога была криво зациклена** (копии всего окружения с шагом 36 м внахлёст) — теперь квартал
  режется плоскостями отсечения по чистым границам [−10; 17,98] м, копии чередуются прямые и
  зеркальные, поэтому каждый стык симметричен. Пул из 6 копий переставляется по ходу машины.
- **Лось пробегал сквозь дома и телепортировался** — в клипах `Sprint`/`Run`/`Death` кость
  `RigRoot_01` уезжала на 4–6 м за цикл (root motion), на повторе цикла лось прыгал назад.
  Горизонтальный сдвиг корня обнуляется при загрузке, положение лося задаёт сцена.
- **Лось проваливался под асфальт в конце** — после удара он больше не «опрокидывается» поворотом
  всей модели, а ложится клипом `Lying_Breathing_01`; плюс страховка: самая низкая кость скелета
  всегда не ниже 6 см над землёй.
- **Время зависело от fps** — кадр двигает сцену ровно на реальный `dt` (в замедлении ×1/3),
  разбитый на равные подшаги ≤ 1/240 с. Длительность и траектория одинаковы при любом fps,
  замедление плавное, без рывков. Тряска камеры тоже по времени сцены.
- **Машина не реагировала на окружение** — из квартала извлекаются препятствия по «подошве»
  (фонари Ø 0,11 м, стволы Ø 0,17 м, скамейки 1,66×0,44 м), с учётом зеркальных копий.
  Машина упирается в них и останавливается; фонарный столб гнётся от удара.
- **Манекен был не из модели** — используется `wooden_artist_mannequin.glb`: 102 деревянные детали
  разложены на 15 сегментов (голова, грудь, таз, плечо/предплечье/кисть, бедро/голень/стопа)
  с шарнирами в центрах шаров-суставов. Корпус и голова — пружина-демпфер, руки водителя — IK на
  руле, ремень, подушки, окраска зон по тяжести травм из API.
- **Манекены не помещались в салон** — таз ставится на 4 см над верхом подушки (ищется по
  вершинам сиденья), рост подгоняется под потолок конкретной машины.
- **Повторы удалены** — после заезда финальная картина остаётся на экране.
- **Лось выпрыгивает как скример** — прячется за кустом у самой дороги и выскакивает за 0,19 с
  (вдвое быстрее прежнего) в последний момент: за ~0,7 с до машины.
- **Руль — в последний момент** — манёвр начинается за ~0,46 с до лося; машина проходит
  в 0,5–0,9 м от него (проверено по костям скелета на 30/60/90 км/ч, касаний нет).
- **Лось не отлетает вбок при ударе** — при низком капоте опрокидывается на капот и сползает
  вперёд перед бампером, при высоком — отлетает вперёд по ходу.
- Камера «Сбоку» стоит на проезжей части (раньше попадала в крону дерева).
- Смятие кузова: двигаются только вершины зоны смятия, нормали смешиваются из готовых —
  было 28 мс на кадр, теперь применяется раз за кадр и только пока идёт удар.

## Проверка (браузер, `?debug`, Lada Vesta)

| Сценарий | Результат |
|---|---|
| Объезд 60 км/ч, pass | объехал, касаний с лосем нет, возврат в полосу |
| Объезд 70 км/ч, limit | на пределе, крен до 17°, следы шин |
| Объезд 80 км/ч, fail/skid | занос, разворот, упирается в скамейку |
| Объезд 90 км/ч, fail/rollover | встаёт на два колеса, удар в дерево |
| Удар 60 км/ч, medium, roof_hit | удар на 49 км/ч (= `impact_speed` API), лось на капоте, затем лежит перед машиной |
| Выход из теста | улица, машина, материалы, геометрия и камера экскурсии восстановлены |

Ошибок в консоли нет.

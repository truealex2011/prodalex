# Нейросеть и автопоиск 3D-моделей

Идеи взяты из проекта «парсинк» (локальная Qwen через llama.cpp и поиск моделей на Sketchfab), но переписаны под AutoChoice.

## 1. Нейросеть: «Я понял так…»

Файл: [app/llm.py](../app/llm.py). Локальная **Qwen2.5-1.5B-Instruct** запускается через `llama-completion` (llama.cpp) на этом же компьютере: ни облака, ни ключей.

- Модель получает описание клиента и **пересказывает цель простыми словами** (`goal`), а ещё раскладывает текст в профиль: бюджет, места, кузов, коробка, привод, топливо, цвет, пожелания.
- Вывод жёстко ограничен грамматикой GBNF: всегда валидный JSON и только разрешённые значения. Выдумать поле или значение она не может.
- **Машину нейросеть не выбирает.** Подбор остаётся детерминированным ([recommender.py](../app/recommender.py)). Нейросеть только заполняет профиль.
- Защита от выдумок ([nlu.py](../app/nlu.py), `parse_ex`): числа и жёсткие условия из текста проверяют правила и перекрывают нейросеть; бюджет принимается, только если в тексте есть число.
- Пересказ показывается пользователю на шаге уточнений, на экране загрузки и в карточке «Подробнее».
- **Без модели сайт работает как раньше** на правилах (`nlu.parse`); при сбое или таймауте (75 с) тоже.

Установка (≈1,1 ГБ модель + ≈25 МБ llama.cpp, с проверкой SHA-256): `powershell -File tools\setup_llm.ps1`, затем перезапуск сайта. Файлы лежат в `%USERPROFILE%\.cache\autochoice`. Если стоит «парсинк», его файлы подхватываются сами. Переменные: `AUTOCHOICE_LLAMA`, `AUTOCHOICE_MODEL`, `AUTOCHOICE_LLM_TIMEOUT`.

## 2. 3D-модель файлом, иначе фото

Файлы: [app/sketchfab.py](../app/sketchfab.py), [app/photos.py](../app/photos.py), [app/media.py](../app/media.py), эндпоинт `GET /api/v1/cars/<id>/media`.

Для машины **без собственной разобранной модели** (она есть только у Vesta и Sportage):

1. Поиск на **Sketchfab** (публичный API, только скачиваемые модели) по «марка модель [год]», при неудаче — по сокращённому названию.
2. Отбор: совпадение названия, года и кузова; без деталей, low-poly и игрушек; лицензия **Creative Commons без ND** (мы перекрашиваем кузов). NonCommercial допускается, пока проект некоммерческий (`SKETCHFAB_ALLOW_NC=0` запретит).
3. Файл **скачивается на наш сервер как GLB** (`app/static/media/models/sf/<uid>.glb`), а не встраивается чужим плеером. Источник файла: официальный Sketchfab Download API, если задан `SKETCHFAB_TOKEN`; иначе зеркало Objaverse (датасет с GLB моделей Sketchfab под CC; его индекс скачивается один раз, ≈110 МБ в `data/cache`).
4. Проверка файла: автономный GLB без внешних ссылок, до 96 МБ, до 1,2 млн полигонов, **габариты как у одной легковой машины** (отсекает сцены с дорогой, двумя машинами и россыпью деталей).
5. Автор и лицензия сохраняются в `car_assets`, выводятся в карточке «Подробнее» (CC требует указания автора).
6. **Модели нет → фото** с Wikimedia Commons (свободные лицензии, горизонтальные, название содержит марку и модель, автор указан под снимком). Показываются галереей вместо 3D.

Результат кэшируется в БД (`car_assets.origin`, `car_media_checks`): повторно сеть не нужна. «Модели нет» перепроверяется раз в неделю, при недоступности источника — через 10 минут. Первый поиск занимает 10–90 секунд (при первом запуске — ещё и индекс).

## Ограничения

- Найденные модели могут быть «не той» комплектации или года; название в источнике — единственный признак.
- Направление «нос/корма» чужой модели автоматически не определяется: длина выравнивается по оси, но модель иногда стоит задом.
- У найденных моделей нет разметки деталей, поэтому подсказки на узлах не показываются; тест на лося работает со своей заглушкой.
- Зеркало Objaverse содержит лишь часть моделей Sketchfab, поэтому часть машин получает фото.

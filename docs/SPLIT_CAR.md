# Автоматическое разбиение автомобиля

Из корня проекта, Python 3 и NumPy (`python -m pip install numpy`):

```powershell
python tools/split_car.py "$HOME\Downloads\lada_vesta.glb" --out "$HOME\Downloads\vesta_auto"
```

В результате появятся `car_parts.glb` и `parts.json`. Каждая запись JSON перечисляет имена узлов, число треугольников и мировую ограничивающую коробку (`bbox`). Если деталь занимает несколько исходных узлов, фрагменты имеют общий `extras.part_id` и перечислены в `nodes`. Исходные опорные узлы, материалы, UV, нормали и атрибуция сохраняются. Уже существующие файлы результата скрипт не перезаписывает.

**Какие модели подходят:** один автомобиль без окружающей сцены, статический GLB 2.0, Y вверх. По умолчанию нос смотрит в −Z; для других направлений укажите, например, `--front=+X`. Длинные оси и размеры оцениваются в мировых координатах, без изменения масштаба. Риг, анимации и сжатые меши сначала нужно экспортировать как обычную статическую модель.

**Как читать результат:** колёса ищутся по дискообразной форме, одинаковой высоте и расположению парами. Двери, капот, крышка багажника, крыша, зеркала, переднее и заднее стекло и бамперы ищутся среди связных островков по пропорциям и месту на машине. Цвет и название материала не участвуют. `approximate` означает «кандидат, проверить», `unclassified` — исходная геометрия, назначение которой скрипт не определил. Скрипт не восстанавливает салон или зазоры, если их нет в сетке. На кузове, состоящем из одной оболочки, результат может ограничиться колёсами.

**Откуда берутся сведения об автомобиле:** [NHTSA vPIC](https://vpic.nhtsa.dot.gov/api/) — открытый каталог без API-ключа, преимущественно для рынка США. Для поиска используются поля `asset.extras.make/model`; если их нет — короткое название или имя файла вида `lada_vesta`. Это подсказка для поиска, а не распознавание по внешности. Для многословных марок и неоднозначных имён лучше указать данные явно:

```powershell
python tools/split_car.py focus.glb --make Ford --model Focus --year 2018 --out focus_parts
python tools/split_car.py my_car.glb --vin ВАШ_17_ЗНАЧНЫЙ_VIN --out vin_parts
```

По марке и модели проверяется наличие модели в каталоге. По VIN дополнительно возвращаются доступные поля комплектации: тип кузова, привод, двигатель и топливо. Поля могут быть неполными (`partial`). VIN отправляется только если он указан явно; GLB никуда не отправляется. При отсутствии совпадения (`not_found`) или связи (`unavailable`) геометрия всё равно сохраняется.

# Доработка: 3D-тест на лося — на той же улице, что и экскурсия

Ты уже делал эту задачу по `docs/PROMPT_moose_test_3d.md`. Всё оттуда про лося, манекенов, физику
разрушений, исходы API, вид сзади и проверку остаётся в силе, **кроме одного: тест больше не идёт
в отдельном окне со своей сценой.** Он идёт прямо в основной 3D-сцене экскурсии (`viewer.js`) —
на той же городской улице, с той же уже загруженной машиной. Работай в
`C:\Users\1\Desktop\AutoChoice\autochoice`. Текущая версия (`moose3d.js` с отдельным рендерером
в `#mm-canvas`) сделана примерно на 20% — её переделать, «облегчённая версия» не принимается.

## 1. Как должно работать для пользователя
1. Пользователь смотрит машину на улице (экскурсия по прокрутке) и нажимает «🦌 Тест на лося».
2. Экскурсия ставится на паузу (прокрутка не двигает камеру, сноски и кнопки «Подробнее / Не то /
   Нравится» скрыты). Внизу экрана — панель теста поверх сцены: слайдер скорости 30–90 км/ч,
   «Объехать лося» / «Не успеть — удар», камеры «Погоня / Сзади / Сбоку / Сверху», карточка результата
   (используй существующую разметку и `renderMoose()` из `app.js`).
3. Та же машина, что на экране, отъезжает назад по улице, разгоняется, лось резко выпрыгивает из-за
   деревьев на тротуаре — дальше объезд или удар, повтор сзади, результат.
4. «×» — машина плавно возвращается на место стоянки (`ENVIRONMENT.carSpot`), все повреждения
   откатываются, лось и обломки убираются, экскурсия продолжается с того шага, где была.
5. Отдельное окно `#moose-modal` с 3D-рендерером больше не используется. Оставь его только для
   2D-fallback (`moose2d.js`) — если ассеты теста не загрузились.

## 2. Факты о сцене (`app/static/js/viewer.js`)
- `ENVIRONMENT`: улица из `static/media/env/street.glb`, масштаб ×5 (метры). Улица идёт вдоль **+X**.
  Проезжая часть z ∈ [0,5; 6,5], двойная жёлтая около z ≈ 3,65; полоса машины (правая) — z ≈ 5,0,
  встречная — z ≈ 2,2. Тротуары с деревьями z ∈ [−3; 0] и [7; 10], дальше дома, за ними стены-задники
  (`backdrops`).
- Машина: `carRoot` в `carSpot = {x: 8, y: 0.02, z: 5.0, yaw: −π/2}` — носом в **+X**, её левая
  сторона — **−Z** (встречная полоса). Объезд — влево, к z ≈ 2 и обратно.
- Улица конечная: прямой квартал x ∈ [≈ −14,2; 17,98], слева перекрёсток x ≈ [−30; −14], справа
  в x = 17,98 пристыковано **зеркальное отражение** улицы (`mirrorAt`, `pivot.scale.x = −1`).
  Разметка достроена до стыка (`extendMarkings`).
- После загрузки у окружения `matrixAutoUpdate = false`. Деревья (`treePattern`) уже умеют становиться
  полупрозрачными, если закрывают машину (`collectTrees` / `updateTreeFade`) — используй это и в тесте.
- Камера экскурсии не выходит за коридор `corridor` (z ∈ [−1,5; 8,5]), иначе влетает в дома. Камеры
  теста тоже держи внутри коридора улицы.
- `tick()` вызывает `applyCamera()` (экскурсия) и `updateCallouts()`. Добавь режим, в котором вместо
  этого камерой и машиной управляет тест.
- **Ловушка:** `loadModel()` кэширует модель и отдаёт `clone(true)` — геометрия **общая** с кэшем.
  Перед деформацией вершин клонируй геометрию нужных мешей, а при выходе возвращай исходную —
  иначе смятый капот останется у всех следующих машин.

## 3. Зацикленная улица
Тест не должен упираться в конец улицы. Сделай «беговую дорожку» из этой же улицы: впереди машины
по ходу движения подставляй следующие копии квартала (чередуй оригинал и зеркальное отражение, как
сейчас сделан стык в 17,98 — так разметка, бордюры и дома совпадают), позади — убирай. Либо держи
машину около места и двигай окружение назад с переносом на период. Требования: ни одного шва
с голой землёй, разметка непрерывна, координаты не растут бесконечно, после выхода из теста улица
возвращается к исходному виду. Для экскурсии ничего не должно поменяться.

## 4. Найденные дефекты текущей версии (все исправить)
1. В объезде лось не появляется вообще.
2. Исход API не показан: при 90 км/ч API дал `fail` + `skid`, а машина плавно сдвигается без заноса.
   Ветки `limit`, `fail+skid`, `fail+rollover` не реализованы.
3. Машина не едет: скорость со слайдера на движение не влияет.
4. Объезд в неправильную сторону.
5. Дорога не зациклена.
6. Нет манекенов, подушек, ремней, рук на руле, окраски зон травм по `collision.seats`.
7. Нет физики разрушений — только подсветка `damaged_parts`. Нужно: смятие переда и капота,
   продавленная крыша при `roof_hit`, трещины или осколки лобового стекла, отлетающие бампер,
   решётка и зеркало (гравитация, отскок, трение).
8. Лось не выпрыгивает из кустов, а летит по центру дороги. После удара оказывается позади машины.
9. Масштаб лося считается по полной высоте с головой и рогами — холка ниже 1,9 м. Считай по кости
   холки (`RigChest_013` / `RigSpine2_012`).
10. «Повтор сзади» не повторяет заезд. Нужна запись состояний каждого кадра и настоящий replay
    с камеры позади машины в замедлении ×3.
11. Камеры — фиксированные точки мира. Они должны следовать за машиной.
12. Цикл отрисовки отдельной сцены не останавливается после закрытия окна. (При переходе в основную
    сцену отдельный рендерер должен исчезнуть совсем.)
13. `app/static/media/moose/mannequin_rig.glb` лежит в публичной папке и отдаётся сервером, хотя
    лицензия «Sketchfab Standard» не подтверждена. Убери файл из `static/` (например, в
    `assets_private/` + `.gitignore`), подключай только по флагу `MANNEQUIN_LICENSE_OK=1`. Без флага —
    **собственный процедурный манекен** из примитивов (капсулы, сферы, суставы, жёлто-чёрные маркеры
    краш-теста). Сцена должна быть полной и без чужой модели.
14. Риг манекена неполный (6 частей, руки не отделены). Нужны плечо, предплечье, кисть, бедро, голень,
    стопа — для рук на руле и реакции на удар.

## 5. Манекены в этой машине
Посади троих (водитель, пассажир спереди, сзади) по габаритам деталей `seat_driver`,
`seat_passenger`, `seat_rear` из `parts.json`, руки водителя — на `steering_wheel`. Стёкла уже
полупрозрачные. Для вида сбоку сделай «рентген»: кузов полупрозрачный или плоскость отсечения,
чтобы было видно салон.

## 6. Критерии приёмки — проверь каждый и приложи числа и скриншоты
Прогоняй без `requestAnimationFrame` (вкладка может быть скрыта): в режиме `?debug` выстави
доступ к тесту и гоняй `step(1/60)` до конца. Скриншоты — через `renderer.domElement.toDataURL()`.

| Сценарий | Скорость | Что должно быть (измеримо) |
| --- | --- | --- |
| объезд `pass` | 50 | лось видим ≥ 1 с; машина проходит ≥ 40 м; уход влево (к z ≈ 2) на 2,5–3,5 м и возврат в полосу (|z − 5| < 0,3 в конце); крен ≤ 8° |
| объезд `limit` | ≈ `v_max` | то же + крен 12–25°, ≥ 2 колебания курса, следы шин |
| объезд `fail`+`skid` | 90 | рыскание > 60°, машина на колёсах, останавливается |
| объезд `fail`+`rollover` | машина с этим режимом (например, LADA Niva Legend) | крен > 30°, отрыв колёс одной стороны |
| удар `roof_hit=true` | 60 | торможение до `impact_speed` ±2 км/ч; лось на лобовом и крыше; крыша продавлена; стекло разрушено; ≥ 1 отлетевшая деталь |
| удар `roof_hit=false` | 60 (кроссовер, например RAV4) | капот и бампер смяты, лось отброшен вперёд и в сторону |
| манекены | любой удар | 3 манекена пристёгнуты; подушки спереди раскрываются ≤ 50 мс после удара; рывок и отскок; затем цвета зон по `collision.seats` |
| повтор сзади | все | настоящий повтор с камеры позади машины ×3, видны крен и манекены |
| улица | все | за заезд ≥ 60 м без швов и пустоты; камеры не влетают в дома |
| выход | все | машина на `carSpot`, повреждения откатаны (геометрия совпадает с исходной), лось и обломки убраны, экскурсия на том же шаге и работает, следующая подобранная машина без повреждений |

Плюс:
- одинаковые `result` и скорость дают одинаковую анимацию (фиксированный seed);
- мобильный 375×812: машина видна над панелью теста (можно `camera.setViewOffset`), без
  горизонтальной прокрутки;
- в консоли нет ошибок; `pytest -q tests` — 15 зелёных; бэкенд и ответы API не меняются;
- 2D-fallback работает, если ассеты теста недоступны.

## 7. Запуск
PostgreSQL + `python wsgi.py` с `DATABASE_URL` (см. README) или `.claude/launch.json`; страница
`http://localhost:8000/?debug` → подбор → «🦌 Тест на лося».
